## 🔬 研究方向

聚焦**大语言模型与自主智能体**，尤其是让它们真正“能干活”的训练环节：

- **大模型后训练** —— SFT、偏好优化（RLHF / DPO）、奖励建模
- **强化学习** —— 面向推理与智能体决策的 RL（RLVR、长程信用分配）
- **智能体系统** —— 工具调用、多智能体编排与评测
