## Current Focus

### Polynoia / AgentHub

[Polynoia](https://github.com/JuneQQQ/polynoia) is an IM-style multi-agent workspace for building software through chat.

It coordinates Claude Code, Codex, OpenCode, and custom agents in one conversation, with:

- 1:1 chats and group chats for agent collaboration
- Orchestrator-driven task decomposition, validation, and merge flow
- Inline previews for code diffs, Markdown, HTML, DOCX, PPTX, XLSX, and workspace files
- Git-backed workspaces, commit history, conflict handling, and mobile / desktop clients

## Selected Work

### Deep Past

[Deep Past](https://github.com/JuneQQQ/deep_past) is a low-resource Akkadian-to-English translation system and Kaggle Silver Medal solution.

It combines sentence alignment, ByT5 continued pretraining / SFT, R-Drop / Coverage Loss, and hybrid MBR-style inference.
